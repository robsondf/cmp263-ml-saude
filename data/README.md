# Dados e proveniência

Nenhuma base adquirida ou selecionada. `manifest.json` é um formulário de proveniência pendente, não prova de download. Não colocar microdados no Git. Diretórios `raw/`, `interim/`, `processed/` e `cache/` estão ignorados.

Registrar URL exata do recurso, data, versão, licença/termos, dicionário, SHA-256 do arquivo bruto, esquema, elegibilidade, total antes/depois, distribuição do alvo e exclusões. Se houver mais de um arquivo/ano, criar uma entrada por arquivo. Um cache no Drive deve usar pasta exclusiva `cmp263-ml-saude` e não pode ser o único meio de reprodução.
